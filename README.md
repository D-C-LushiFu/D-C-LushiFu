## 💭 我的创作理念

**想法优先，限制其次。**

我相信创造力不应该被传统思维所限制。

有时候，解决问题最好的办法就是换一种思路。有时候，一个看似不切实际的想法，反而会成为作品中最有趣的部分。

我喜欢尝试、学习、犯错、修复问题，以及在过程中发现意料之外的可能性。

我不只是想使用现有的工具。

**我也想创造属于自己的工具。**
